## Runtime and build inventory

- .NET 8 SDK 8.0.428 installed **inside this workspace** for the session. The official Windows x64 ZIP was checked against Microsoft's SHA-512 metadata before use. .NET/ASP.NET Core/WinForms runtime files in self-contained outputs retain their included license and ThirdPartyNotices files.
- Explicit product NuGet dependency: `NAudio.Wasapi 2.2.1`; transitive `NAudio.Core 2.2.1`. Package nuspecs declare MIT and Mark Heath 2023. [Third-party notices](../THIRD_PARTY_NOTICES.md) include the license.
- Windows SDK .NET reference contracts and WinRT projection are implicitly selected by `net8.0-windows10.0.19041.0`: package Microsoft.Windows.SDK.NET.Ref 10.0.19041.56, with WinRT.Runtime 2.2.0. The package requires Windows SDK license acceptance; it is not represented as a generic MIT SDK. The original SDK license, runtime redistribution list and separate MIT C#/WinRT notice are preserved under docs/licenses and in the portable distribution. No unsupported Windows audio policy COM interface is used.
- Kestrel comes from the Microsoft.AspNetCore.App shared framework, not a custom HTTP parser or browser runtime. The tray uses native WinForms.
- iOS frameworks: Foundation, UIKit, AVFoundation, AudioToolbox, MediaPlayer, Security, ImageIO, CommonCrypto and libc. These are Apple platform SDK/system frameworks, not redistributed third-party source. A compatible legally available SDK must be supplied externally.
- OpenSSH is an external executable already present on Windows. Only fixed named diagnostics, key authentication and strict known-host verification are supported. No OpenSSH binary is bundled.
- Tests use a small executable test runner with actual sockets. No unit-test framework packages, Electron, WebViews, cloud SDKs, codecs, virtual drivers, or archive extraction libraries are required.

See `docs/reports/dependency-audit.json` for the actual NuGet advisory query. A clean query covers known NuGet advisories only; it does not certify source safety, Windows security support, iOS security, or Apple binaries.

## API sources

- [Microsoft GSMTC manager](https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportcontrolssessionmanager): Windows 10 1809, apps must expose media sessions.
- [NAudio 2.2.1 WasapiCapture source](https://github.com/naudio/NAudio/blob/v2.2.1/NAudio.Wasapi/WasapiCapture.cs): shared-mode PCM conversion flags.
- [Windows notification listener](https://learn.microsoft.com/en-us/windows/uwp/design/shell/tiles-and-notifications/notification-listener): declared capability and interactive consent.
- [Apple audio playback category](https://developer.apple.com/documentation/avfaudio/avaudiosession/category-swift.struct/playback): audio background mode and screen lock.
- [Apple AudioQueueNewOutput](https://developer.apple.com/documentation/audiotoolbox/audioqueuenewoutput(_:_:_:_:_:_:_:)): interleaved PCM playback queue.
- [Theos Linux/Windows setup](https://theos.dev/docs/installation-linux): external toolchain requirements.
