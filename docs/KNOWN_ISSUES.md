# Known issues and practical limits

1. **End-to-end USB audio remains blocked.** The physical iPhone is present, but its agent and SSH ports refuse connections, and no iOS SDK/build/signing chain is available. Native source has not compiled. This is the primary remaining release gate.
2. **Native UI, background audio, routes, interruptions and Jetsam behavior are unverified.** Portable C test success does not establish Objective-C linkage, app packaging, iOS scheduling or acoustic output. No native memory-budget claim is made.
3. **UIKit lifetime limits worker autonomy.** Without active audio the OS may suspend the app; termination interrupts jobs. There is no launchd worker or daemon/UI IPC yet.
4. **Direct media handoff is partial.** AVPlayer invocation lacks a completion/error protocol and coordination with the ongoing PCM stream. Leave deviceHasInternet false for normal USB operation. No YouTube provider, DRM handling or independent network connectivity is supplied.
5. **Notification consent packaging is missing.** The collector compiles but does not request consent in this unpackaged console/tray. Use explicit local PublishEvent integrations until a reviewed package/consent flow exists.
6. **Storage retention is basic.** New uploads reserve against a default two-GiB total quota, with a 64-MiB free-space admission reserve, at most 256 complete files and sixteen partial transfers. There is no automatic partial cleanup, retention/versioning or transactional backup snapshot. Replacing a file requires quota space for both versions until commit. Native quota code is source only. Archives remain opaque and are never extracted.
7. **Restart/resume is not block-delta backup.** Reconnect resumes a verified file prefix. Historical job IDs return previous state; full argument conflict detection is not persisted across restart. Retried work must use a new job ID.
8. **Text word counts differ for Unicode whitespace.** Native iOS uses ASCII whitespace; .NET uses Unicode whitespace. ASCII text fixtures agree. Define a common text contract before cross-device Unicode acceptance.
9. **Transport confidentiality is limited to the local/USB trust boundary.** HMAC authenticates the session; frames are not encrypted or individually MACed. No public-network mode is supported.
10. **Windows output selection is absent.** The app captures the current multimedia endpoint and follows changes, but does not install a sound driver, switch the default endpoint, or mute local Windows speakers automatically.
11. **Media capability and artwork coverage depend on applications.** Play/pause/seek were tested with a real Windows fixture. Third-party artwork, next/previous and live browser behavior still need broader acceptance tests. Large or invalid images may be omitted.
12. **Performance evidence is short and simulator based.** The final two-minute combined run was clean, but two memory snapshots do not prove absence of leaks. No overnight stability, end-to-end latency, battery or thermal measurements exist. Scoped 1 ms Windows timers can increase power use while streaming.
13. **Tray and iOS visuals have no manual inspection record.** The WinForms tray compiles; iOS UI remains source only. The app has no custom icon or fully validated launch-screen resources.
14. **SSH is a library integration, not an enrolled device connection.** It requires an existing authorized SSH service, loopback forward, private identity and verified known-host record. No device SSH command was executed.
