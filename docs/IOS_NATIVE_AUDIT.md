# Native iOS audit

Follow-up to `738a497`, 2026-11-18. Every native source/header and resource in `src/iOS`, plus shared `bt_wire.c/.h`, was reviewed. The code compiles against actual iPhoneOS 12.4 headers for iOS 12.0 / baseline ARM64. All seven translation units passed warnings-as-errors and Clang's path-sensitive analyzer. Headers are compiled through their consuming translation units. None of the Objective-C runtime behavior has been verified on the phone because execution/installation was rejected.

The linked frameworks are UIKit (UI only), Foundation, AVFoundation, AudioToolbox, MediaPlayer (UI only), Security, ImageIO (UI only), CoreGraphics and QuartzCore (UI only), with Apple system libraries/CommonCrypto/dispatch. Framework/API declarations used are present in the iOS 12.4 SDK; `-Werror=unguarded-availability-new` checks declared newer APIs. This cannot detect all runtime policy, scheduling, entitlement or framework behavior.

`python tests/ios_build_test.py` performs eight artifact checks: ARM64/iOS minimum/public-library linkage; rejection of ARM64e/newer deployment; both signature hashes; code-corruption rejection; plist/launch-resource corruption rejection; iPhone 6 resource consistency; Debian member/path/permission/executable checks; deterministic package output and manifest hashes. No SDK/framework binaries or session keys occur in package payloads.

The analyzer initially reported one nullable transfer-ID diagnostic. After explicit validation, all seven reports have zero diagnostics. The custom ad-hoc verifier checks actual SHA-256 CodeDirectory and resource hashes. apple-codesign 0.29.0's experimental verifier treats missing CMS in ad-hoc signatures as an error; that was not used as a success assertion. Device installation independently rejected the signature, so no trust/installation claim is inferred from local hash validity.

Remaining known native assumptions: UIKit background lifetime depends on active audio; standalone audio permissions are unproven; Unicode word counting differs from .NET; archive retention is basic; AVPlayer handoff is partial; native quota/restart/worker behavior has no device evidence. First real PCM playback takes precedence over feature expansion.
